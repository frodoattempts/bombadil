# bombadil

Research into testable versions of the simulation hypothesis: the idea that
the observable universe is a computation.

We treat "the universe is a simulation" as a family of narrower,
falsifiable sub-hypotheses about how a simulator would be built. Examples are a
spacetime lattice, finite resolution, rendering on demand and bounded compute.
For each one we ask what it predicts, what data already constrains, and where
new analysis is possible.

## Current direction

The survey's leading candidate (R1) is a search for **cubic-symmetric
anisotropy** in the arrival directions of ultra-high-energy cosmic rays. Beane,
Davoudi & Savage (2014) predicted this signature of a lattice-simulated
universe. The search would use the Pierre Auger Observatory's public data and
would first be validated on simulated skies.
